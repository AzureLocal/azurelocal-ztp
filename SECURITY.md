# Security Policy

## Supported Versions

We actively support the following versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us as follows:

1. **Do not** create a public GitHub issue
2. Email security@azurelocal.cloud with details
3. Include steps to reproduce and potential impact
4. We will acknowledge receipt within 48 hours
5. We will provide regular updates on our progress

## Security Considerations

This repository contains infrastructure as code for deploying Azure Local solutions. Please ensure:

- Never commit secrets or credentials
- Use GitHub secrets for CI/CD
- Follow principle of least privilege
- Regularly rotate access keys and tokens
